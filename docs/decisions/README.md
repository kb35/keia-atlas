# Decision records

Each file here records one design decision: the situation, the options, what was chosen and what it costs. They're kept short and never rewritten. If a decision changes, a new record replaces the old one and the old one is marked superseded.

The format follows Michael Nygard's architecture decision records. See [adr.github.io](https://adr.github.io/).
